# Rain

Rain 是一个日志包浏览与检索工具。把日志上传到一个 Issue（用于归集同一次问题排查的日志），就可以浏览文件树、分页查看内容、搜索关键词，并分享文件或搜索标签的链接。

支持文本日志和 `.zip`、`.tar.gz`、`.tgz`、`.gz`、`.7z` 压缩包；压缩包里的日志也能直接浏览和搜索。

## 下载与启动

从 [Releases](https://github.com/SwartzMss/Rain/releases) 下载适合系统的发布包：Windows x64 使用 ZIP，Linux x64 使用 tar.gz。使用发布包无需安装 Node.js、Rust 或额外的数据库服务。版本以下载包内的 `VERSION` 文件为准。

1. 解压发布包，保持程序、`.env` 和 `VERSION` 位于同一目录。
2. 用文本编辑器打开 `.env`，填写首次安装的管理员密码：

   ```dotenv
   RAIN_BOOTSTRAP_ADMIN_USERNAME=admin
   RAIN_BOOTSTRAP_ADMIN_PASSWORD=请替换为你自己的强密码
   ```

   密码长度为 8～128 个字符。空数据库首次启动必须填写；已有管理员的密码不会被这两个配置覆盖。

3. 在解压目录中启动程序。

   Windows PowerShell：

   ```powershell
   .\Rain.exe
   ```

   Linux：

   ```bash
   chmod +x ./rain
   ./rain
   ```

4. 打开 <http://localhost:8078>。

使用管理员账户登录后，可在“系统设置”中管理注册、容量和自动清理等策略。上传日志需要另外注册一个普通账户：管理员账户负责运营管理，不拥有普通账户的上传权限。

需要从源码运行或自行构建？见[开发与构建](docs/development.md)。

## 开始使用

1. 注册普通账户，注册成功后登录。
2. 新建或选择一个 Issue，例如 `CN013`。
3. 拖拽或选择日志文件上传，等待后台处理完成。
4. 点击 Issue 的“查看”，在左侧文件树选择文件，右侧分页查看文本。
5. 输入关键词搜索日志，点击命中结果定位到原文件。

一个 Issue 可以包含多次上传。二进制文件会显示文件信息，登录后可下载，但不能文字预览或搜索正文。

### 搜索、保存与分享

- **关键词搜索**：支持标识符、错误码和连续中文的部分匹配；Issue / 日志包关键词搜索至少输入 3 个字符。
- **详细搜索**：可使用 `ERROR AND NOT timeout` 等表达式筛选内容，也可继续搜索当前结果。
- **保存条件**：普通用户登录后，可保存到“我的搜索条件”，以后在当前打开的 Issue 中复用。
- **分享标签**：使用文件或搜索标签的分享功能复制链接。搜索链接会重新执行查询，不是结果快照；接收方需要能访问同一个 Rain 服务，源日志也必须仍然存在。跨机器分享时，请通过对方可访问的服务地址打开 Rain 后再复制链接。

详细搜索的预览结果保留 30 分钟，完整结果保留 7 天；读取不会延长有效期。过期后可重新搜索。

### 账户与权限

| 身份 | 浏览与搜索 | 下载 | 创建 Issue、上传和删除 | 运营管理 |
| --- | --- | --- | --- | --- |
| 游客 | 可以 | 不可以 | 不可以 | 不可以 |
| 普通用户 | 可以 | 可以 | 仅自己的 Issue | 不可以 |
| 管理员 | 可以 | 可以 | 不可以 | 可以 |

用户名为 3～32 个字符，可使用字母、数字、`.`、`_`、`-`，不区分大小写。支持修改密码和退出登录，暂不支持自助找回密码。

## 常用设置与数据

在程序旁的 `.env` 修改以下启动设置，保存后重启：

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `SERVER_PORT` | `8078` | 服务端口 |
| `SERVER_HOST` | `0.0.0.0` | 监听地址；仅本机使用可改为 `127.0.0.1` |
| `DATABASE_URL` | `sqlite://./data/rain.db` | 数据库位置 |
| `RAIN_DATA_ROOT` | `./data/uploads` | 文件与索引目录 |
| `RAIN_LOG_DIR` | `./log` | 运行日志目录 |

建议从解压目录启动，避免相对数据路径随工作目录变化；长期部署可以使用绝对路径。容量、注册和自动清理策略在管理员“系统设置”中修改，页面会提示哪些更改需要重启。更多设置见[配置说明](docs/configuration.md)。

升级或迁移前，停止 Rain 并备份数据库、文件目录和 `.env`，它们需要配套保留。保持 `RESET_DB=false`；设为 `true` 会清空数据。详见[部署与维护](docs/operations.md)。

## 使用限制与常见问题

- **适用环境**：当前面向可信内网部署，通过 Rain 提供的页面访问。每个数据库由一个 Rain 实例使用，数据放在本地磁盘。
- **文件格式**：暂不支持 `.rar`、加密压缩包、分卷 `.7z.001` 或自解压 EXE。
- **容量与过期**：每个 Issue 默认最多 8 GiB 最终可浏览文件；默认 7 天非活跃后自动清理。仅浏览文件或搜索不会刷新活动时间，关注页面显示的过期提示；需要长期保留时请联系管理员调整策略。
- **上传状态**：上传进度表示传输进度，传输完成后还要等待解压和索引。处理失败时查看页面原因及运行日志。
- **内容被截断**：超长日志行、过大的分页响应或搜索结果可能触发限制；需要完整原文时可登录下载源文件。
- **启动失败**：确认首次管理员密码已填写、端口未被占用、数据目录可写；排查方法见[部署与维护](docs/operations.md)。
- **分享打不开**：检查接收方能否访问链接中的地址，以及 Issue / 文件是否已被删除或自动清理。
